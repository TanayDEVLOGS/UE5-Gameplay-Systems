# AI Systems

Basic enemy AI systems built in Unreal Engine 5 using Blueprints.

## Features

### Patrol
- Patrol between defined locations
- AI Move To implementation

### Detection
- Pawn Sensing
- Player detection
- Detection state handling

### Chase
- AI follows the player after detection
- Movement toward the player
- Chase state handling

### Combat
- AI attack behavior
- Attack animation integration
- Player damage interaction

### Death
- AI health system
- Death detection
- Death animation
- AI stops functioning after death

## Concepts Practiced

- AI movement
- Pawn Sensing
- AI Move To
- Gameplay states
- Event-driven logic
- Health and damage systems
- Animation integration
- Blueprint functions
