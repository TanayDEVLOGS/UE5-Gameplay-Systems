# Sprint System

A sprint system built in Unreal Engine 5 using Blueprints.

## Features

- Sprint activation
- Increased movement speed while sprinting
- Stamina depletion while sprinting
- Stamina regeneration
- Sprint restrictions when stamina is depleted
- Smooth transition between movement speeds

## Concepts Practiced

- Character movement
- Timelines
- Lerp
- Boolean state management
- Stamina management
- Reusable Blueprint functions
- Debugging gameplay logic

## Future Improvements

- Better sprint state architecture
- Animation integration improvements
- More scalable stamina management
