# Jump, Dodge & Dash System

Jump, dodge, and dash movement systems built in Unreal Engine 5 using Blueprints.

## Features

### Jump
- Custom jump logic
- Stamina cost
- Jump restriction when stamina is insufficient
- Integration with the character movement system

### Dodge
- Directional dodge movement
- Dodge animation integration
- Stamina cost
- Controlled dodge movement

### Dash
- Dash movement
- Dash animation integration
- Stamina cost
- Controlled movement during dash

## Concepts Practiced

- Character movement
- Input handling
- Direction-based movement
- Timelines
- Stamina management
- Boolean state management
- Blueprint functions
- Animation integration
- Gameplay state management
