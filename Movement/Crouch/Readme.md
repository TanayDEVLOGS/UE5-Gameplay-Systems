# Crouch System

A basic crouching system built in Unreal Engine 5 using Blueprints.

## Features

- Crouch activation
- Crouch movement
- Character capsule height adjustment
- Stand-up transition

## Concepts Practiced

- Character movement
- Capsule Component manipulation
- Input handling
- Boolean state management
- Blueprint logic

## Future Improvements

- Crouch animations
- Crouch movement speed
- Crouch-to-stand obstruction checks
- Improved transition handling
